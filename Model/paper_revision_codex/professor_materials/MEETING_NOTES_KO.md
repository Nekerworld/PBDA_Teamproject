# 교수님께 설명드릴 핵심 요약

교수님, 기존 코드와 재구성 데이터를 확인하고 공통 시간순 8:2 조건에서 다시 실험했습니다. Hybrid가 두 지표의 세 seed 평균 모두 가장 높았습니다. RetailRocket의 공통 시간순 80:20 분할에서 seed 42·43·44의 평균을 비교했습니다. Hybrid의 NDCG@50은 0.117177, Recall@50은 0.166260입니다.

1. Validation을 train에서 분리한 것 자체가 오류는 아니었습니다. 기존 GNN은 분리 전에 전파 그래프를 만들어 validation 관계 139,306개가 그래프에 남아 있었습니다. 이번에는 선택 단계의 그래프를 내부 학습 구간만으로 구성했습니다.

2. IF가 구매를 모두 제거하는 현상을 재현했습니다. 저장 라벨과 재적합 라벨이 100% 일치했습니다. 행동코드 평균·표준편차를 빼면 구매 3,476건은 남지만 14,388건은 여전히 제거됩니다. 따라서 봇 제거라고 설명하거나 행동코드 두 특징만의 문제라고 단정할 수 없습니다. 본실험은 IF 없이 공통 core-3을 적용해 구매 17,305건을 보존했습니다.

3. 원고 식 8과 달리 최종 융합에서 BPR 신호가 빠지던 점을 수정했습니다. 후보 수·MF/GNN 비중·재고 가중은 내부 validation의 NDCG와 Recall 공동 기준으로 선택했습니다. 첫 v3는 Recall이 부족해 추가로 세 validation seed 평균에서 설정을 고정했고, 기존 단독 LightGCN은 유지했습니다. 재사용 가능한 모델은 보존하고 필요한 모델만 재학습했습니다.

4. 각 지표의 가장 강한 비교 모델 대비 상대 차이는 NDCG +10.83%, Recall +1.27%입니다. 이 문서의 결과는 기존 논문의 점수를 재사용하지 않고 이번 실행에서 산출한 값입니다. LightGCN 대비 Recall 평균 차이는 +0.002078이지만 사용자 bootstrap 95% 신뢰구간 [-0.003267, +0.007539]은 0을 포함합니다. 평균 1위와 통계적으로 확실한 Recall 우위는 구분해야 합니다.

5. 원고는 새 데이터 분할과 평가 분모, 이분그래프, 실제 점수 계산, 재고 관측 시점과 시간 측정 조건에 맞춰 수정해야 합니다. 기존 0.7대 Recall과 이번 값을 동일 조건의 전후 성능으로 비교하지 않았습니다. 과거 시험 결과를 이미 확인한 연구 과정이라는 한계도 기록했습니다.

통제 비교에서는 MF 점수를 뺀 조건의 Recall이 전체 Hybrid보다 높고 NDCG는 낮았습니다. 모든 구성요소가 모든 지표를 높인다는 주장과, 주요 baseline 대비 두 지표 평균 1위라는 결과를 구분해야 합니다.
