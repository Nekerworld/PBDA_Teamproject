# 동일 수치의 설정 평가 가속

v4의 세 seed validation 선택 기준과 576설정은 변경하지 않는다. 후보별 MF/GNN 정규화 및 RRF 순위를 재사용하고, 최종 Top-50을 고를 때 전체 정렬 대신 경계값을 먼저 구한다. 경계값과 동점인 상품을 모두 포함한 뒤 기존 상품 ID 정렬 규칙을 적용한다. 최종 추천 CSV를 만드는 코드는 기존 구현을 유지한다.

seed 42의 실제 3층 GNN에서 기존 v4의 576개 설정 전체 지표와 새 계산을 비교하고, 사용자별 추천 목록의 일치를 별도로 확인한 뒤 사용한다. fast_validation_parity.json에 오차와 검사 범위를 남긴다. 합성 동점·빈 목록·2만 후보의 Top-K 경계와 캐시 결합도 검사한다.

v4의 완료된 검증 모델과 설정 CSV를 재사용하는 v5를 별도 폴더에 실행한다. 사용 중인 소스를 덮어쓰지 않고 안전한 완료 시점에 v4를 종료한 뒤 source_v4_before_scoring_optimization을 보존한다. 수치 학습 코드·데이터 해시가 같은 경우에만 아티팩트를 재사용한다. 이 변경은 성능 목표·비교 모델·평가 정답·탐색 범위를 바꾸지 않는다.
