Hybrid 추천 모델 개정 실험 보고

권유희 교수님 검토용 · 2026년 10월 17일 · 공통 시간순 분할과 실제 재실험 결과

Hybrid의 두 지표 동시 1위 목표는 달성하지 못했습니다. 공통 시간순 80:20 분할에서 seed 42·43·44의 평균을 비교했습니다. Hybrid의 NDCG@50은 0.116096, Recall@50은 0.159659입니다.

각 지표의 가장 강한 비교 모델 대비 상대 차이는 NDCG +9.81%, Recall -2.75%입니다. 이 문서의 결과는 기존 논문의 점수를 재사용하지 않고 이번 실행에서 산출한 값입니다.

정답은 시험 구간의 장바구니·구매 상품 집합입니다. 모든 모델의 성적표 분모는 동일한 854명이며, Hybrid에서 추천 목록이 없는 425명도 0점으로 포함했습니다. ±는 세 seed의 표본 표준편차이며 신뢰구간과 다릅니다.

코드에서 바꾼 부분과 선택 근거



MF 신호 보존 원고 식 8은 후보 점수인 ALS+BPR과 GNN 점수를 결합합니다. 기존 코드는 최종 결합에 ALS만 사용했습니다. 이를 수정해 BPR이 후보 검색 이후에도 최종 순위에 기여하도록 했습니다.

후보 검색 MF 결합 점수로 검색하는 방식과 ALS·BPR 후보를 균형 있게 합치는 방식을 비교했습니다. GNN으로 전체 카탈로그를 검색하는 방식으로 바꾸지는 않았습니다.

공동 선택 기준 validation NDCG만 최대화하는 대신 NDCG와 Recall의 상대 개선율 중 작은 값을 최대화했습니다. 한 지표가 좋아지는 대신 다른 지표가 나빠지는 설정을 피하려는 기준입니다.

GNN 학습 64차원 2층·3층 LightGCN에서 행동 가중 InfoNCE를 사용했습니다. 음성 수는 32개, 온도는 0.2입니다. 균등·MF 기반 혼합 표본을 비교하고 학습 이력 상품을 음성에서 제외했습니다. 학습 MF도 같은 학습 구간만 사용합니다. 원고의 GNN BPR 손실 설명은 실제 목적함수에 맞춰 수정해야 합니다.

최종 융합 후보 안에서 MF와 GNN 점수를 각각 min-max 정규화한 뒤 가중합합니다. MF 점수는 ALS 단독이 아니라 ALS+BPR 결합 점수입니다.

![pipeline](figures/pipeline.png)

![validation_tradeoff](figures/validation_tradeoff.png)

점선은 각 지표의 가장 강한 validation 비교 모델을 나타냅니다. 별표는 공동 기준으로 선택한 Hybrid입니다. 점과 색은 실제 설정 탐색 CSV에서 생성했습니다.

학습 곡선과 gamma 민감도는 모두 내부 validation 결과입니다. 최종 test 곡선을 보고 gamma나 epoch를 선택하지 않았습니다. gamma가 1이면 재고 가중은 중립입니다.

재고 가중은 학습 종료 전에 관측한 마지막 available 값을 사용하고 미상 상품에는 부스팅을 적용하지 않습니다. 시험 기간의 실시간 재고나 매출 효과를 검증한 결과는 아닙니다.

원고에서 수정할 내용 공통 8:2와 정답 집합, 식 6~9의 실제 점수 계산, 이분그래프 구조, 데이터 손실 통계, 성능과 실행시간 표, 그림 번호와 해상도를 함께 수정해야 합니다. 속성·카테고리 그래프 및 cold-start 해결 주장은 현재 구현에 맞게 조정해야 합니다.

재현 방법과 판단의 한계



최종 설정은 selection.json으로 확정한 뒤 재학습했고, 각 seed의 완료 파일은 그 설정 해시를 참조합니다. 학습·추천·평가의 원본 CSV와 사용자별 지표를 함께 저장했습니다. synthetic 회귀검사는 프로토콜 확인용이며 실제 데이터 성능으로 사용하지 않았습니다.

이번 전체 실행 기록의 소요 시간은 1.95시간입니다. 학습 환경과 장비는 experiment_plan.json, 코드 및 데이터 식별자는 각 manifest에 기록했습니다.

과거 프로젝트의 test 결과는 이번 작업 전에 이미 검토된 상태입니다. 이번 설정 탐색은 내부 validation에서만 진행했지만, 이 자료를 연구 전체에서 한 번도 관찰하지 않은 독립 시험이라고 부르지는 않습니다. 단일 데이터셋·단일 시간 구간·세 seed의 정정 평가라는 범위를 명시합니다.

투고 원고의 NDCG 0.3710과 Recall 0.7113은 이번과 데이터 분할·후보 처리·평가 분모가 다릅니다. 해당 숫자와 이번 결과를 같은 조건의 전후 성능으로 비교하거나 상대 개선율을 계산하지 않습니다.

추천 시간은 모델 로딩을 제외하고 사용자 배치를 CPU에서 3회 실행한 중앙값을 seed별로 구한 뒤 평균한 값입니다. 사용자당 값은 배치 시간을 나눈 환산치이며 온라인 응답 지연시간이 아닙니다. MF 기반 음성 채굴을 사용한 GNN의 학습 시간에는 MF 의존 비용을 포함합니다.

이 측정에서 Hybrid의 배치 추천 시간은 GNN 단독의 4.53배였습니다. GNN 점수를 계산하는 후보 수가 줄어도 MF 검색 비용이 추가되므로 전체 속도 향상을 보장하지는 않습니다. 원고의 계산 효율 우위 주장은 이 측정 범위에 맞춰 수정해야 합니다.
