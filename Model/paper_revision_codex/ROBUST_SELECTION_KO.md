# 추가 검증: 세 seed의 내부 validation으로 설정 선택

2026-10-17. v3의 바깥 시험 결과를 확인한 후 작성했다. v3는 NDCG@50 1위였지만 Recall@50이 기존 LightGCN보다 낮아 두 지표 동시 1위 목표를 달성하지 못했다. 이번 추가 연구가 시험 결과와 완전히 독립적인 최초 가설이었다고 주장하지 않는다. 새 설정의 수치 선택에는 바깥 시험 라벨·지표를 전달하지 않는다.

단일 seed validation의 변동성을 줄이기 위해 42·43·44에서 동일한 내부 시간 분할로 학습한다. 42에서 이미 학습한 체크포인트는 재사용한다. 추가 두 seed는 42의 검증에서 고정한 epoch를 사용한다. 비교할 GNN은 2층 uniform 125epoch, 3층 uniform 190epoch, 2층 MF혼합 130epoch이다. 각 모델의 수치 학습 구현과 데이터는 v3와 같다.

각 backbone마다 alpha .25/.5, MF blend/균형 합집합, 후보 5천/1만/2만, minmax/RRF, MF 가중 .1/.2/.3/.4/.5/.7, gamma 1/1.1/1.25/1.5의 576설정을 비교한다. 세 validation seed의 평균 NDCG·Recall과 각 지표 최강 비교값의 상대 차이 중 작은 값을 최대화한다. 테스트 지표가 아닌 validation 평균으로 한 설정을 고정한다.

기존 standalone LightGCN 3층 uniform 190epoch를 유지해 baseline을 약하게 교체하지 않는다. 기존 최종 MF와 GNN이 같은 수치 모델이면 재사용하고, 다른 Hybrid backbone만 필요할 때 재학습한다. 모든 최종 추천 CSV를 다시 평가하고 독립 검산한다.

이 단계가 성공하지 않더라도 실패 결과를 보존하며, 평가 사용자를 제외하거나 정답 분모를 바꾸지 않는다. 처음 시도한 v3의 실패와 추가 선택 과정을 최종 보고서에 명시한다.
