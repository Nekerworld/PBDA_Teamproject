# Hybrid 개선 실행 계획

사용자 승인 범위: 실제 코드 수정, RetailRocket 실험, 시각화, 교수님 설명 자료 작성. 교수님께 직접 전송하지 않는다.

목표는 공통 시간순 8:2, original 평가 집합에서 세 seed 평균 NDCG@50과 Recall@50이 ALS, BPR, ALS+BPR, LightGCN보다 모두 높은 Hybrid다. MF 후보 검색과 GNN 재정렬 골격을 유지하고, 사용자 선택에 따라 이분그래프를 사용한다. 전체 예산은 RTX 3090 Ti 1대에서 24시간이다.

1. 기존 코드와 근거를 보존하고 이 폴더에서만 수정한다. 공통 8:2 IF 없는 준비 데이터를 검증해서 재사용한다. raw 자료는 프로젝트 data에서 읽는다.
2. 최종 MF 점수에서 사라졌던 BPR 신호를 복원한다. 점수 전달·정답 독립성·분모·음성 표본 검사 후 실제 학습을 시작한다.
3. 내부 검증에서 MF 결합 비중, MF 후보 혼합과 합집합, 후보 수, MF/GNN 융합과 gamma를 탐색한다. 공동 지표의 최소 상대 개선율을 선택 기준으로 쓴다.
4. GNN은 64차원 2층/3층과 균등/학습 MF 기반 혼합 음성의 네 조건을 비교한다. 전체 예산에서 마지막 8시간을 최종 재학습과 산출물 검증에 남긴다.
5. validation에서 모델과 epoch를 확정한 selection.json을 저장한 뒤 outer train에 재학습한다. seed 42,43,44로 최종 평가하며 original 사용자 누락은 0점이다.
6. 실제 CSV에서 표와 그림을 생성한다. 원본 문제와 수정 내용, 정확한 분할 건수, IF 구매 제거 원인, 성능과 한계를 교수님 설명용 문서에 정리한다. 문서는 렌더링 후 확인한다.

기존 outer test 점수는 이 연구 과정에서 이미 관찰됐다. 이번 실험은 학습과 선택에 outer test 라벨을 전달하지 않는 정정 평가이며, 과거에 완전히 미관찰이었던 시험이라고 주장하지 않는다.

중단과 복구: 실패 시 로그와 완료 마커를 먼저 검사한다. 성공한 학습을 무조건 재실행하지 않는다. 데이터·코드·계획 해시가 다르면 새 실험 디렉터리를 사용한다. 목표 미달은 성공으로 표시하지 않고 결과 및 차이를 보고한다.
