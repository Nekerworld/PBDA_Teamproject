# 논문에 넣을 수정 문장

제출 PDF는 아직 고치지 않았다. 아래 문장은 이번 코드의 프로토콜을 설명하기 위한 초안이며, 실험을 마친 성능 수치를 포함하지 않는다. 기존 논문의 성능 표를 이 프로토콜의 결과로 두면 안 된다.

## 데이터 분할과 필터

유효 이벤트를 시간 순서대로 80:20으로 나눈다. 같은 timestamp는 학습과 평가로 갈라지지 않으며, 비율은 Isolation Forest와 core filtering 이전의 유효 이벤트 기준이다. 이상치 탐지와 core filtering, 상품 속성은 각 구간의 경계 이전 기록만 사용한다.

기본 모델은 Isolation Forest를 적용하지 않는다. 이벤트 행 수가 사용자와 상품 모두 3 이상일 때까지 core filtering을 반복한다. 이 기준은 서로 다른 이웃의 수가 아니다. Isolation Forest를 유지한 조건과 고유 이웃 수 기준 core는 별도의 비교이며, 테스트 성능으로 선택하지 않았다. Isolation Forest의 이상치 라벨은 봇을 식별한 결과가 아니다.

## 평가

비교에 쓰는 사용자와 원래의 positive 상품은 필터 전에 고정한다. positive는 add-to-cart와 transaction이다. 같은 사용자와 같은 원래 정답으로 모든 필터 조건을 평가한다. 필터 때문에 학습에서 제외된 사용자는 추천 목록이 없고, 그 사용자의 지표는 0이다. 필터 후 남은 사용자와 상품만으로 계산한 조건부 지표는 따로 보고하며, 그 조건부 Recall이 원래 정답 전체에 대한 Recall을 뜻하지는 않는다.

## 모델

ALS의 신뢰도는 `1 + 1.5 * r_ui`이다. `r_ui`는 view 1, add-to-cart 6, transaction 12를 사용자·상품 쌍에 합한 값이다. BPR은 같은 값을 pairwise loss의 가중치로 사용한다. 관측 여부만 같고 가중치가 다른 행렬이 같은 요인으로 학습되던 implicit BPR은 사용하지 않는다.

LightGCN의 그래프는 관측된 사용자·상품 쌍을 비가중 간선으로 연결한다. 행동 종류는 간선 종류가 아니라 pairwise loss의 가중치로 반영된다. 상품 속성 노드는 속성 이름과 값의 쌍이다. 값은 학습 구간의 최신 기록만 사용하고, 숫자 값은 학습 데이터 안의 분위 구간으로 묶는다. 범주 트리는 categoryid로 연결한다. 재고 여부 `available`은 그래프 노드로 넣지 않고, 후보 재정렬에서만 배수 gamma를 곱한다.

gamma는 외부 테스트가 아니라 시간순 내부 검증의 NDCG로 고른다. 후보 500개는 ALS와 BPR의 결합 점수에서 만들고, 그 후보 안에서 ALS와 LightGCN 점수를 정규화해 결합한 뒤 gamma를 적용하고 정렬한다. 반복 구매 가능성이 있으므로 학습에서 본 상품도 다시 추천할 수 있다. 테스트 정답은 후보를 만드는 데 쓰지 않는다.

## 이번 프로토콜의 측정 결과

아래 숫자는 `retailrocket_v3`의 sealed CSV에서 읽은 값이다. 제출 PDF의 기존 표와 바꾸어 쓰면 안 된다. 합성 테스트와 짧은 epoch 연결 확인의 숫자는 여기에 없다.

기본 조건은 Isolation Forest 없이 이벤트 행 수 core 3이다. 고정 reference 사용자는 854명이다. 대표 지표는 이 854명의 원래 테스트 positive에 대한 K=50이다. 학습에서 빠진 425명은 추천이 없어 0점이다. seed 42, 43, 44의 평균과 표본 표준편차는 다음과 같다.

| 모델 | NDCG@50 | Recall@50 |
|---|---:|---:|
| ALS | 0.0675 ± 0.0003 | 0.1183 ± 0.0018 |
| BPR | 0.1018 ± 0.0012 | 0.1354 ± 0.0028 |
| ALS+BPR | 0.0994 ± 0.0005 | 0.1458 ± 0.0008 |
| LightGCN | 0.0223 ± 0.0010 | 0.0414 ± 0.0036 |
| Hybrid | 0.0582 ± 0.0009 | 0.1122 ± 0.0017 |

같은 사용자·같은 seed에서 Hybrid에서 ALS+BPR을 뺀 NDCG 차이의 사용자 bootstrap 95% 구간은 세 seed 모두 0보다 작다(약 −0.041, 구간 대략 −0.053에서 −0.030). 이 프로토콜에서는 LightGCN 재정렬이 ALS+BPR 후보 생성을 개선하지 않았다.

같은 854명 중 필터 후 남은 409명만 보는 조건부 K=50은 분모가 다르므로 위 표와 비교하면 안 된다. 그 조건부 Hybrid NDCG@50 평균은 0.124, Recall@50 평균은 0.242다. 후보 500개의 원래 정답 Recall은 세 seed 평균 0.194이고, 같은 후보의 조건부 Recall은 0.424다.

gamma는 세 기본 seed 모두 내부 검증 original NDCG로 1.5가 선택됐다. 검증 곡선에서 2.0은 1.5보다 낮았다. Isolation Forest를 켠 조건은 학습 구매가 0건이고 Hybrid original NDCG@50은 0.0067이다. 고유 이웃 core와 과거 메타데이터 ablation의 Hybrid는 기본 조건보다 낮았고, 그 paired 구간에 0이 없다. 이진 pairwise와 속성 이름만 쓰는 ablation의 Hybrid 차이는 구간에 0이 포함된다.

사용자 bootstrap은 끝난 seed에 대한 사용자 단위 구간이며 시간 분할의 불확실성이 아니다.
